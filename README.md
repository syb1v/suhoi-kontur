# Сухой Контур

SEO-платформа инженерной компании по дренажу и водоотведению.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Открыть `http://localhost:3000`. Админка доступна по `/admin`; dashboard на текущем этапе использует demo-данные, внешние интеграции описаны в `BACKLOG.md`.

## Маршруты

- `/` — публичная посадочная страница и калькулятор
- `/admin` — административный dashboard-заготовка

## Статус

Сейчас реализован визуальный MVP без внешних credentials: публичная страница, калькулятор, демонстрационные кейсы и каркас админки. Следующий этап — подключение Drizzle/SQLite, реальной авторизации, CRUD-контента и API заявок.
