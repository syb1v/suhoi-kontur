# Технический долг и внешние зависимости

## Блокирует production

- [ ] Зарегистрировать домен и настроить DNS/SSL.
- [ ] Купить рабочий номер и добавить его в настройки сайта.
- [ ] Создать доменную почту и SMTP-провайдера.
- [ ] Зарегистрировать Telegram-бота и закрытый чат.
- [ ] Подключить WhatsApp Business-ссылку.
- [ ] Внести реквизиты ООО и утвердить юридические тексты.
- [ ] Подготовить реальные кейсы, фото и подтверждение прав на материалы.
- [ ] Создать production PostgreSQL и object storage для медиа.
- [ ] Настроить резервное копирование базы и deployment.

## Интеграции

- [ ] Получить идентификатор Яндекс Метрики и включить внешний счётчик.
- [ ] Подключить amoCRM или Битрикс24.
- [ ] Включить Telegram-уведомления: задать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (адаптер уже готов).
- [ ] Реализовать SMTP-отправку после выбора почтового провайдера.

## Контент и CMS

- [x] CRUD кейсов: тексты, метрики, порядок, видимость, загрузка фото (локальный адаптер).
- [x] Редактирование услуг: названия, пояснения, порядок, видимость.
- [x] Настройки: телефон, почта, мессенджеры, ставки, ID Яндекс Метрики.
- [x] Публикация изменений: ISR + мгновенная ревалидация после сохранения.
- [ ] Загрузка фото в объектное хранилище (S3-совместимое) вместо `public/uploads`.
- [ ] Редактор остальных секций главной (hero, FAQ, партнёрский блок).
- [ ] Редактирование SEO-полей страниц услуг и регионов.

## Безопасность

- [ ] Отозвать ранее опубликованный ключ ModelHub и создать новый через переменную окружения OpenCode.
- [x] Локальная авторизация админки: `ADMIN_PASSWORD` + подписанная сессия (`SESSION_SECRET`).
- [x] Rate limit на вход (8 попыток / 10 минут) и httpOnly cookie.
- [ ] Задать production `ADMIN_PASSWORD` и `SESSION_SECRET`, отличные от локальных.
